Граф состоит из 47 узлов (точек) и 73 рёбер. Узлы представляют собой ключевые точки СМП (порты, проливы). Рёбра соединяют узлы напрямую, образуя сеть маршрутов. У каждого узла есть координаты (широта/долгота), необходимые для отображения на карте. Рёбра имеют атрибут status, определяющий режим движения, и length для расчёта расстояний.
